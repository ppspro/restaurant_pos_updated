# Coding Standards

## 1. Naming Conventions
- **Folders**: lowercase kebab-case (e.g. `billing-module`, `shared-components`).
- **Files**: camelCase or PascalCase for TSX components (e.g. `CartItem.tsx`).
- **TypeScript**: Use interfaces for models/entities. End types in `.types.ts`.

## 2. Git Workflow
- **Commit Style**: Semantic Commits (`feat: add cart`, `fix: token reset`, `docs: update FRS`).
- **Branch Naming**: `feature/`, `bugfix/`, `refactor/`.
