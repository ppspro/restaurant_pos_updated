# Screen List

1. **Login Page**: Secured credentials input.
2. **POS Cashier Billing Portal**: Grid view of menu items, category filters, cart list, payment checkout sidebar.
3. **Admin Dashboard**: Visual overview cards of today's sales, active orders, and quick stats.
4. **Reports Screen**: Interactive tables to generate daily/monthly sales, KOT lists, cashier productivity, and audit logs.
5. **Settings Portal**: Tax rules config, database backups, printer configuration.
