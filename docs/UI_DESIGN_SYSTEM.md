# UI Design System

## 1. Typography & Theme
- **Font Family**: Inter, sans-serif.
- **Colors**: Sleek dark mode ready base theme.
  - Primary: `#18181b` (Slate-900)
  - Secondary: `#f4f4f5` (Slate-100)
  - Accent: `#2563eb` (Blue-600)
  - Background: White (Light), Black/Slate-950 (Dark)

## 2. Target Performance Benchmarks
- **Billing Checkout Confirmation**: < 2 seconds.
- **Thermal Receipt Dispatched**: < 1 second.
- **Reports Dashboard Load**: < 500ms.
