# Printer Architecture

## 1. Layout Margins & Dimensions
- **58mm Layout**: Margin left/right 0, text line wrapping at 32 characters.
- **80mm Layout**: Margin left/right 3mm, text line wrapping at 48 characters.

## 2. Printer Types
- **Kitchen Printer**: Network IP ethernet printer receiving raw ESC/POS KOT scripts.
- **Receipt Printer**: POS local USB thermal printer printing Customer & Restaurant copies.
