# POS User Experience Guidelines

## 1. Cashier Workflow Targets
- **Max Clicks to Checkout**: 3 clicks once cart is full.
- **Grid Layout**: Large touch targets (min 48px x 48px) for fast selection.
- **Keyboard Shortcuts**: Key bindings for quick cart clear, pay, and search bar focus.

## 2. Loading & Error States
- Button loaders visible during transaction requests to prevent double checkouts.
- Graceful, non-intrusive warnings on printer offline alerts.
